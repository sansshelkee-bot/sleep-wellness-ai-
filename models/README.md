# Trained Machine Learning Model Artifacts

This directory stores serialized models, preprocessing pipelines, and evaluation metrics generated by `ml/train_model.py`.

## Artifact Inventory
1. `sleep_model.cbm`: Native CatBoost multi-class classifier model with native SHAP TreeExplainer compatibility.
2. `deployment_model.pkl`: Serialized best-performing deployment ensemble model (Voting Classifier combining CatBoost, Random Forest, and Gradient Boosting).
3. `preprocessor.pkl`: Serialized `SleepDataPreprocessor` containing the fitted Scikit-Learn `ColumnTransformer` (StandardScaler + OneHotEncoder).
4. `model_metrics.json`: Empirical benchmark evaluation results (Accuracy, Precision, Recall, F1-Score, Confusion Matrices, ROC-AUC) across all candidate models on the unseen 20% test split (3,000 samples).
5. `model_metadata.json`: Feature names, hyperparameters, target classes, and framework metadata.

## Re-training Command
To re-train the models at any time:
```bash
python ml/train_model.py
```
